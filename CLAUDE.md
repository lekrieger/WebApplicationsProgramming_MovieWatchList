# Movie Watch List

Project 6 of the Web Applications Programming seminar (Romanian-American University).
Team: Leon and Dennis. Pre-exam project, deadline mid-December 2026.

## Working rules
- Do not make assumptions. When something is unclear or missing, ask before acting.
- Write no code until asked. Follow docs/plan.md and do only the step asked for, then stop.
- Everything is in English: app UI, code, comments, commit messages, README and docs.
- Work in small, sequential steps. Never output the whole app at once. Each step ends in a working state and one git commit, so the history shows many commits from both team members.
- Never run git commit or git push. Leon and Dennis make all commits. At the end of each step, suggest a short commit message.
- Leon and Dennis must both be able to explain every part of the code. Keep code simple and explain choices when asked.

## Course requirements
- HTML, CSS and JavaScript, plus a framework from the course: Node.js + Express backend, SQLite database, static HTML pages with plain CSS and vanilla JavaScript using fetch.
- Data persists after a page refresh and a restart, using a database or a backend (localStorage is not enough).
- At least 4 pages or views, with navigation between them.
- Validated forms: empty or invalid input shows a clear error instead of breaking the app.
- Responsive layout: usable on laptop and phone.
- Git commits from both team members across the module.
- README with what the app does and how to run it.

## Project 6 must-haves
- Add films (typed in by hand, no movie API).
- Mark films as watched.
- Rating from 1 to 5 stars with an optional short review (max 300 characters).
- Sort by rating or by release date.
- Not doing the 19/20 challenge (no accounts, roles, private data or uploads).
